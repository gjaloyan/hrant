# MCP

## Что это
Model Context Protocol (MCP) — открытый стандарт и фреймворк от Anthropic (ноябрь 2024) для стандартизации подключения AI-систем (LLM) к внешним инструментам, данным и системам. Универсальный интерфейс для интеграции AI-приложений (Claude, ChatGPT) с источниками данных (файлы, БД), инструментами (поисковики, калькуляторы) и рабочими процессами.

## Ключевые параметры
- Дата релиза: ноябрь 2024
- Статус: open-source
- Архитектура: клиент-серверная модель
- Разработчик стандарта: Anthropic

## Практические заметки
- Работает как "USB-C порт" для AI — единый стандарт подключения к разным системам
- Позволяет AI читать файлы, обращаться к БД, использовать внешние инструменты
- Применим в корпоративных средах для безопасного подключения AI к данным
- Устраняет необходимость создавать отдельные интеграции для каждого источника данных
