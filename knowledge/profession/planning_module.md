# planning module

## Что это
Sewage Facilities Planning Module — модуль планирования канализационных сооружений, обязательный документ для новых проектов землепользования в рамках программы Act 537 (Пенсильвания, США). Представляет собой формализованную процедуру согласования систем сбора и очистки сточных вод.

## Ключевые параметры
- **Форма заявки**: 3800-CD-BCW0359 (Application Mailer)
- **Форма Component 3**: 3850-FM-BCW0353 (для систем сбора и очистки)
- **Исключения**: проекты, соответствующие требованиям Component 1, освобождены от подачи Application Mailer
- **Компоненты**: минимум 3 типа (Component 1, 3 и Application Mailer упомянуты)

## Практические заметки
- Application Mailer — обязательный первый шаг для всех новых проектов землепользования
- Component 1 позволяет упростить процедуру для квалифицированных проектов
- Component 3 используется для планирования систем сбора и очистки сточных вод
- Требуется проверка соответствия проекта критериям Component 1 перед подачей полного пакета

## Частые ошибки
- Подача полного модуля для проектов, подпадающих под Component 1 (избыточная бюрократия)
- Пропуск этапа Application Mailer при начале проекта
- Использование неактуальных номеров форм при подаче документов
