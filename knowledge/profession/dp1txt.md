# dp1.txt

## Что это
`%~dp1` — расширение параметра Windows CMD: берёт аргумент `%1`, убирает внешние кавычки (`~`) и возвращает только диск (`d`) и путь (`p`) без имени файла. Пример: `C:\utils\MyFile.txt` -> `C:\utils\`.

## Ключевые параметры
- `%0` — имя/команда batch-файла.
- `%1`, `%2`, ... `%9` — позиционные аргументы batch-файла.
- `%*` — все аргументы, до `%255`.
- `%~1` — `%1` без окружающих кавычек.
- `%~d1` — только диск: `C:`.
- `%~p1` — только путь: `\utils\`, включает завершающий `\`.
- `%~dp1` — диск + путь: `C:\utils\`.
- `%~f1` — полный путь.
- `%~n1` — имя без расширения.
- `%~x1` — расширение.
- `%~nx1` — имя + расширение.
- `%~s1` / `%~sp1` — короткий 8.3-формат, если существует.

## Практические заметки
- Использовать `%~dp0` для пути к текущему `.bat`-файлу, `%~dp1` — для пути к первому переданному файлу/аргументу.
- Аргументы с пробелами передавать в двойных кавычках.
- Если аргумент может быть пустым, также заключать его в кавычки, чтобы не сдвигались номера `%1`, `%2`.
- Сохранять результат в именованную переменную: `SET _LogFile=%~dp1`.
- Для проверки реального существования файла/папки использовать `IF EXISTS`, так как расширение параметров не гарантирует существование.

## Частые ошибки
- Ожидание, что `%~dp1` проверяет наличие файла -> не проверяет; добавить `IF EXISTS`.
- Путь из `%~p1` содержит завершающий `\` -> некоторые команды могут трактовать его как escape-символ; учитывать при кавычках и конкатенации.
- Файл без диска/пути с `%~f1` считается находящимся в текущей директории -> результат может быть неверным.
- Точка в имени каталога трактуется как расширение -> `%~n1` может обрезать имя; использовать `%1` или `%~nx1`.
- В batch-файле внутри `FOR` нужен двойной процент: `%%~dG`, `%%~pG`, а не `%~dG`.

## Причинно-следственные связи
- `~` в `%~dp1` causes удаление окружающих кавычек из `%1`
- `d` modifier causes возврат только буквы диска
- `p` modifier causes возврат только пути с завершающим `\`
- combined `d` + `p` enables получение каталога аргумента без имени файла
- аргумент с пробелами без кавычек causes неправильное разбиение на параметры
- wildcard argument causes использование первого найденного совпадения при расширении
- отсутствие drive/path в аргументе causes `%~f1` считать файл расположенным в текущей директории
