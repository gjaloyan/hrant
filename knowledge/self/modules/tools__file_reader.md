# backend/tools/file_reader.py

## Purpose
Модуль предоставляет функцию чтения файлов разных форматов: текстовых файлов с опциональным выбором диапазона строк, PDF через pypdf, DOCX через python-docx, а также изображений с сообщением о том, что OCR не реализован. Для неподдерживаемых форматов, отсутствующих файлов и ошибок чтения возвращаются диагностические строки.

## Public interface
- `read_file` (function) - Читает файл с ограничением по числу символов; для текстовых форматов поддерживает выбор диапазона строк с нумерацией.

## Dependencies
(none)

## Notes
Диапазон строк для текстовых файлов задаётся 1-based и включительно по обоим концам, а max_chars применяется после нарезки. PDF и DOCX читаются только при наличии соответствующих сторонних библиотек; изображения не распознаются, возвращаются только метаданные.
