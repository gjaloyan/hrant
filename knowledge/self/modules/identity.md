# backend/identity.py

## Purpose
Модуль управляет постоянной идентичностью агента в каталоге knowledge/identity: создаёт при первом запуске дефолтные soul.md, identity.md и user.md, читает их для подмешивания в системный контекст, формирует preamble с приоритетными override-блоками имени и языка, а также аккуратно обновляет user.md фактами о пользователе без полной перезаписи ручных правок. Для изменений user.md сохраняются снапшоты в _history, а добавление фактов выполняет простую текстовую дедупликацию внутри соответствующей секции.

## Public interface
- `UserFactCategory` (constant) - Тип категорий фактов о пользователе: language, style, about_user или rule.
- `IdentityManager` (class) - Менеджер файлов идентичности агента, профиля пользователя и истории изменений user.md.
- `IDENTITY` (constant) - Глобальный экземпляр IdentityManager для использования остальной частью приложения.

## Dependencies
- backend.config

## Notes
Модуль уважает существующие файлы и создаёт дефолты только при отсутствии файлов, поэтому ручные правки не затираются. add_user_fact делает снапшот user.md только перед реальным изменением и не делает его при дедуплицированном повторе. Дедупликация является синтаксической: нормализует маркеры, дату, пробелы, пунктуацию и регистр, но не распознаёт семантически одинаковые формулировки на разных языках.
